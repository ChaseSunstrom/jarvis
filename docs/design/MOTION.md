# Motion when it does things

Reactor II (`README.md` in this folder) settled the look. This is the motion
that goes with it: what moves when Jarvis *does* something, so that a person
glancing at the screen knows what it is doing without reading. One rule
above all: motion reports work; it never decorates. A thing that is not
happening does not move.

## The vocabulary

| Jarvis is… | what moves | where | tokens |
|---|---|---|---|
| idle | the level arc breathes at `idle_breath_level`; blades drift | reactor | `motion.reactor.breathe` |
| listening | the level arc follows the room's amplitude; blades hold | reactor | `motion.reactor.level` |
| thinking | the inner ring sweeps; blades slow to half | reactor | `motion.reactor.think` |
| calling a tool | one blade group lights and sweeps once; a call line draws in from the left with the tool's name, then its result stamps on | reactor, activity strip | `motion.dur.enter`, `motion.ease.out` |
| stepping a task | the task's ring gains one tick; on WORK the plan blade fills | activity strip, WORK | `motion.dur.enter` |
| reading memory | the graph node blinks once; its edges glow for the blink | graph | `motion.dur.blink` |
| reading a sensor | the figure counts to the new value; the row's hairline flashes once | activity strip, HOUSE | `motion.dur.enter` |
| looking at a camera | the lens irises in, the caption says *looking · kitchen*, the lens irises out on the answer | reactor caption | `motion.reactor.iris-a`, `motion.reactor.iris-b` |
| waiting on you | the held bar slides up; its warn rule pulses slowly until answered | held bar | `motion.dur.enter`, `motion.reactor.breathe` |
| speaking | the level arc follows the voice; blades in cadence | reactor | `motion.reactor.speak` (added in M53) |
| an error | the warn rule snaps in; the reactor's rim goes `color.orb.error` for one blink, then the previous state | reactor | `motion.dur.blink` |
| a moment landing | the MOMENTS count ticks up; the new row slides in under the strip | activity strip, moments | `motion.dur.enter` |

Everything on the right is a token in `design/tokens.json`. A new
choreography that needs a duration or an easing that is not there adds the
token first.

## The rules

1. **State, not story.** Each animation is the transition into a state that
   the screen also shows statically (a lit blade, a stamped result, a filled
   ring). Turn animation off and nothing is lost but the transition.
2. **Reduced motion is a state change.** Under `prefers-reduced-motion` every
   row above becomes an instant change with no transition; `motion.spec.ts`
   asserts zero running animations in the reactor's subtree and the strip.
3. **One thing at a time draws the eye.** Concurrent work stacks in the strip
   in order of arrival; only the newest row animates in, the rest are still.
4. **Nothing loops without a reason.** The only continuous motions are the
   idle breath, listening, thinking and speaking — the states a person is
   waiting on. A finished thing is still.
5. **No long frames.** Each choreography is measured: no frame over
   `motion.budget.frame` (added in M53), cumulative layout shift under the recorded budget,
   and the recordings in `docs/motion-review/` are regenerated by the gate.

## Where it is measured

`jarvis-web/e2e/motion.spec.ts` drives each row with the mock's events and
records frame timings; `scripts/verify/m53-motion-acts.sh` runs it, the
token lint, and regenerates the signature recordings. The phone draws the
same vocabulary on Canvas from the same state machine
(`tests/contracts/reactor_geometry.json`) — M61.
