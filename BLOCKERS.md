# Blockers

Milestones that could not be finished, with what was tried. A milestone listed
here keeps its failing verify script; `make verify-all` is allowed to be red
for exactly these and nothing else. Re-checked at the start of every session
(`PROCESS.md` §4). Remove an entry when the milestone is ticked.

Entry format:

```
## <milestone id> — <short title>            (added YYYY-MM-DD)
What is blocked: …
Tried: … (commands and errors verbatim)
Would unblock: …
```
